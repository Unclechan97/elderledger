## 3. 数据模型（SQLite DDL）

```sql
CREATE TABLE user (
  id         INTEGER PRIMARY KEY AUTOINCREMENT,
  openid     TEXT NOT NULL UNIQUE,
  nickname   TEXT,
  role       TEXT NOT NULL DEFAULT 'elder',   -- elder | family
  family_of  INTEGER,                          -- family 用户绑定的老人 user.id
  created_at TEXT NOT NULL DEFAULT (datetime('now','localtime'))
);

CREATE TABLE category (
  id     INTEGER PRIMARY KEY AUTOINCREMENT,
  name   TEXT NOT NULL,                        -- 吃饭买菜 / 医疗药品 / ...
  icon   TEXT NOT NULL,                        -- emoji
  color  TEXT NOT NULL,                        -- 品牌色板内取值
  kind   TEXT NOT NULL,                        -- expense | income
  sort   INTEGER NOT NULL DEFAULT 0
);

CREATE TABLE txn (                             -- 避开 SQL 关键字 transaction
  id           INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id      INTEGER NOT NULL REFERENCES user(id),
  kind         TEXT NOT NULL,                  -- expense | income
  amount_fen   INTEGER NOT NULL CHECK (amount_fen > 0),   -- 金额存"分"，防浮点误差
  category_id  INTEGER NOT NULL REFERENCES category(id),
  occurred_on  TEXT NOT NULL,                  -- YYYY-MM-DD
  note         TEXT DEFAULT '',
  source       TEXT NOT NULL,                  -- voice | photo | manual | family
  confidence   REAL,                           -- voice/photo 解析置信度；manual 存 1
  created_at   TEXT NOT NULL DEFAULT (datetime('now','localtime'))
);
CREATE INDEX idx_txn_user_date ON txn(user_id, occurred_on DESC);
CREATE INDEX idx_txn_category  ON txn(category_id);

CREATE TABLE parse_log (                       -- 解析留痕：错误可追溯、prompt 可迭代
  id           INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id      INTEGER,
  source       TEXT NOT NULL,                  -- voice | photo
  raw_text     TEXT,                           -- ASR 转写文本
  llm_output   TEXT,                           -- LLM 原始 JSON
  final_txn_id INTEGER REFERENCES txn(id),
  created_at   TEXT NOT NULL DEFAULT (datetime('now','localtime'))
);
```

预置分类（seed）：支出 8 类 —— 🥬吃饭买菜 / 💊医疗药品 / 💡水电日用 / 🚌交通出行 / 🧧人情往来 / 👕穿衣打扮 / 🎉休闲娱乐 / 📦其他支出；收入 3 类 —— 💰退休金 / 🧑‍🤝‍🧑子女给 / 📥其他收入。

## 4. API 草案（REST，/api 前缀）

| 方法 | 路径 | 入参 | 出参 | 说明 |
|------|------|------|------|------|
| POST | /api/parse/text | `{ text }` | `{ kind, amount_fen, category_id, occurred_on, note, confidence, engine }` | engine: rule \| llm；confidence < 0.7 时前端转预填手动页 |
| POST | /api/parse/image | multipart(file) | 同上 | 图片 ≤ 5MB，识别后不保留原图 |
| POST | /api/asr | multipart(wav) | `{ text }` | 录音上传 → WebSocket 转发 FunASR 容器 → 转写文本 |
| POST | /api/tts | `{ text }` | `audio/mpeg` | edge-tts 合成 mp3；常用短语按文本 hash 缓存 |
| POST | /api/transactions | `{ kind, amount_fen, category_id, occurred_on, note, source, confidence }` | `{ id }` | 确认卡片点"记好了"调用 |
| GET | /api/transactions | `?range=today\|month&page=` | `{ items[], total }` | 明细列表，按 occurred_on 倒序 |
| DELETE | /api/transactions/:id | — | `{ ok }` | 前端已有二次确认 |
| GET | /api/summary | `?period=month` | `{ total_fen, by_category[], diff_last_month_fen }` | 首页大字 + 口语化结论 |
| GET | /api/categories | — | `{ expense[], income[] }` | 九宫格数据 |
| POST | /api/family/bind | `{ invite_code }` | `{ elder }` | P1 |

## 5. LLM Prompt 草案

### 5.1 文本解析（GLM-4-Flash，json_schema 强制输出）

```
System：你是老年人的记账助手。把用户的一句中文口语解析成记账记录。
今天是 {date}（{weekday}）。
支出分类只能是：吃饭买菜/医疗药品/水电日用/交通出行/人情往来/穿衣打扮/休闲娱乐/其他支出；
收入分类只能是：退休金/子女给/其他收入。
规则：
- 口语换算："块"=元、"毛"=角、"两百"=200、"十五块"=15；
- 时间："早上/刚才"=今天，"昨天"=昨天，说不出具体日期就填今天；
- 红包、礼金、随份子 → 人情往来；买菜做饭食材 → 吃饭买菜；
- 收到钱（退休金、孩子给的钱）→ kind=income；
- 金额或分类无法确定时对应字段填 null，并降低 confidence。
User：{text}
```

json_schema（response_format）：

```json
{
  "type": "object",
  "properties": {
    "kind":         { "type": ["string", "null"], "enum": ["expense", "income", null] },
    "amount_fen":   { "type": ["integer", "null"], "minimum": 1 },
    "category_name":{ "type": ["string", "null"] },
    "occurred_on":  { "type": ["string", "null"] },
    "note":         { "type": ["string", "null"] },
    "confidence":   { "type": "number", "minimum": 0, "maximum": 1 }
  },
  "required": ["kind", "amount_fen", "category_name", "occurred_on", "confidence"]
}
```

### 5.2 图片提取（GLM-4V-Flash）

```
System：这是老年人上传的记账凭证照片，可能是购物小票、微信支付截图或支付宝支付截图。
请提取这一笔支出的信息。金额取实付金额（有优惠时取实付）；商户名作为备注；无法确定的字段填 null 并降低 confidence。
User：[image]
```

输出 schema 同上（category_name 由模型给猜测值，服务端映射到分类表，映射不到落"其他支出"）。

## 7. 错误处理与兜底矩阵

| 场景 | 行为 |
|------|------|
| ASR 容器未就绪/超时 | 提示"语音服务没准备好"，引导手动记；app 侧 5s 超时熔断 |
| 麦克风权限被拒 | 大字引导页：设置中开启麦克风权限 |
| ASR 返回空文本 | TTS："没听清，再说一遍或点手动记" → 回语音按钮 |
| LLM 超时/失败 | 正则兜底层接管；都不行 → 预填手动页 |
| 置信度 < 0.7 | 进预填手动页（能确定的字段先填好） |
| 图片 > 5MB | 前端压缩后再试；仍失败提示"请重拍" |
| 图片识别失败 | 提示"没看清"，进手动页 |
| 金额 ≤ 0 或 > 100 万 | 卡片标红提示复核 |
| 弱网/断网 | 顶部明确提示"网络不好"，手动记账可离线暂存本地、联网补传（P1） |
| TTS 播放失败 | 静默降级，不影响主流程 |
