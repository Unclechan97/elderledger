# 05 开发计划

> 版本 v0.1 · 2026-09-11 起步 · 本地开发为基准

## 里程碑

### M0 · 脚手架（1 天）
- 仓库结构（miniprogram/ + server/）；小程序 TS 模板跑通开发者工具
- **Docker Compose 三容器**：app（Express 5 + better-sqlite3）/ asr（FunASR runtime）/ tts（edge-tts）；schema 建表 + 分类 seed
- /api/categories 与 /api/asr 冒烟：录一段测试 wav，FunASR 容器转写成功
- 开发者工具「不校验合法域名」+ 局域网代理配置；.env 接入智谱 Key
- **验收**：模拟器首页请求到预置分类 JSON；`docker compose ps` 三容器健康；测试 wav 转写出正确文本
- **执行记录（2026-09-11）**：脚手架完成并提交（00f0da1）。机器 14GB 内存、空闲仅 0.9GB，**按用户决定 asr 冒烟挪至 M2 开工 spike**（M0 验收缩减为分类 + TTS 两项）；asr 启动前需先腾内存（关大程序或 WSL 限内存重启）。测试语音用 Windows SAPI（Huihui 音色）本地生成，不依赖外网。

### M1 · 手动记账闭环（2 天）
- 手动记账页：大键盘 + 分类九宫格 + 日期选择
- 确认卡片组件（三种输入共用的核心组件）
- 明细列表 + 删除二次确认；首页汇总（/api/summary）
- **验收**：模拟器+真机各手动记 10 笔，汇总与明细准确，金额无浮点尾差
- **执行记录（2026-09-12）**：代码完成并提交（9d64a5f）。服务端记账/明细/汇总三接口 curl 冒烟通过（含 400 校验与删除回滚）；前端 tsc 严格模式零错误。待模拟器/真机人工验收 10 笔。

### M2 · 语音记账（2.5 天）
- RecorderManager 录音（wav 16k 单声道）+ /api/asr（转发 FunASR 容器）；voice-button 组件（按住说话、识别文本大字实时显示）
- /api/parse/text：正则兜底层 + GLM-4-Flash（json_schema）
- /api/tts（edge-tts + 短语缓存）+ TTS 播报（确认前播"对吗"，保存后播"记好了"）；置信度兜底流
- **执行记录（2026-09-12）**：代码完成并提交（aef77f5）。**asr 容器冒烟通过**（机器空闲内存恢复到 2.7GB 后启动成功；两个坑：run_server.sh 须 cd 进脚本目录执行、offline 模式结果帧 is_final 恒 false 靠宽限定时收尾）；/api/asr 全链路 2 秒识别"今天买菜花了，15 块。"；正则解析层 8/8（覆盖"块五/交了三百/五毛八/给我一百二"等口语省略）；TTS GET 通道 8KB mp3。待真机验收（麦克风权限、真实老人口音）。
- **验收**：需求文档 §8 语音用例全部通过；LLM 挂掉时正则层仍可记简单金额；真机从松手到出卡片 ≤ 3s（局域网）

### M3 · 拍照记账（2 天）
- chooseMedia + 压缩上传；/api/parse/image（GLM-4V-Flash）
- 支付截图与小票两类样张各 20 张实测，调 prompt
- 失败/低置信度 → 预填手动页
- **验收**：支付截图金额提取准确率 ≥ 85%（40 张样张）；模糊图正确走兜底

### M4 · 适老化打磨（1.5 天）
- 对照需求文档"设计原则 8 条"逐页走查（字号/触控/对比度/防误触）
- 全局字号调节（标准/大/特大）；TTS 全程覆盖；空态与错误态大字文案
- **验收**：3 位 60+ 真人实测（非开发相关），独立完成"语音记 3 笔 + 查本月花费"，无协助成功率 ≥ 80%

### M5 · 家人协同 + 导出（P1，2 天）
- 邀请码绑定；家人只读汇总/明细；代记标记 source=family
- CSV 按月导出（格式对齐 ezbookkeeping 微信/支付宝导入格式）
- **验收**：两台手机绑定后，子女端看到与老人端一致数据

| 风险 | 等级 | 缓解 |
