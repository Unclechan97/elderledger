# 05 开发计划

> 版本 v0.1 · 2026-09-11 起步 · 本地开发为基准

## 里程碑

### M0 · 脚手架（0.5 天）
- 仓库结构（miniprogram/ + server/）；小程序 TS 模板跑通开发者工具
- Express 5 + better-sqlite3 骨架；schema 建表 + 分类 seed；/api/categories 可调通
- 开发者工具「不校验合法域名」+ 局域网代理配置；.env 接入智谱 Key
- **验收**：模拟器首页请求到预置分类 JSON

### M1 · 手动记账闭环（2 天）
- 手动记账页：大键盘 + 分类九宫格 + 日期选择
- 确认卡片组件（三种输入共用的核心组件）
- 明细列表 + 删除二次确认；首页汇总（/api/summary）
- **验收**：模拟器+真机各手动记 10 笔，汇总与明细准确，金额无浮点尾差

### M2 · 语音记账（2 天）
- WechatSI 插件接入（ASR）；voice-button 组件（按住说话、波形/文字反馈）
- /api/parse/text：正则兜底层 + GLM-4-Flash（json_schema）
- TTS 播报（确认前播"对吗"，保存后播"记好了"）；置信度兜底流
- **验收**：需求文档 §8 语音用例全部通过；LLM 挂掉时正则层仍可记简单金额

### M3 · 拍照记账（2 天）
- chooseMedia + 压缩上传；/api/parse/image（GLM-4V-Flash）
- 支付截图与小票两类样张各 20 张实测，调 prompt
- 失败/低置信度 → 预填手动页
- **验收**：支付截图金额提取准确率 ≥ 85%（40 张样张）；模糊图正确走兜底

### M4 · 适老化打磨（1.5 天）
- 对照需求文档"设计原则 8 条"逐页走查（字号/触控/对比度/防误触）
- 全局字号调节（标准/大/特大）；TTS 全程覆盖；空态与错误态大字文案
- **验收**：3 位 60+ 真人实测（非开发相关），独立完成"语音记 3 笔 + 查本月花费"，无协助成功率 ≥ 80%

### M5 · 家人协同 + 导出（P1，2 天）
- 邀请码绑定；家人只读汇总/明细；代记标记 source=family
- CSV 按月导出（格式对齐 ezbookkeeping 微信/支付宝导入格式）
- **验收**：两台手机绑定后，子女端看到与老人端一致数据

## 测试计划

| 层 | 手段 |
|----|------|
| 服务端解析 | 用例集：口语金额/日期/分类 ≥ 50 条，进 CI 回归（准确率阈值 90%） |
| 图片提取 | 样张库 40 张（小票 20 + 截图 20），prompt 调整后重跑 |
| 小程序交互 | 真机（iOS + Android 各 1）手动用例清单；开发者工具仅做开发 |
| 适老化 | M4 真人实测 3 人；对照工信部规范逐条走查 |

## 风险登记

| 风险 | 等级 | 缓解 |
|------|------|------|
| WechatSI 真机表现与文档不符 | 中 | M2 第一天先做 10 分钟技术验证（spike） |
| GLM-4V 对支付截图提取不稳 | 中 | 样张实测提前到 M3 开头；prompt 迭代；置信度兜底 |
| 免费 API 限流 | 低 | 正则兜底层 + 可配置模型名 |
| 小程序类目审核（个人主体记账类） | 中 | M0 注册时即确认类目；备选"工具>效率"类目 |
| 单人开发节奏 | 中 | M1 先交付完整闭环，语音/拍照为独立增量，任意里程碑可停都可发布 |
